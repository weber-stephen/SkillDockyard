# Organic acquisition strategy

> For the current channel order, use [the complete marketing plan](MARKETING_PLAN.md). LinkedIn is excluded at the founder's request.

## First two weeks

1. **Founder feedback outreach** — Ask warm marketing leads already using Codex or Claude Code to try one campaign brief. Highest qualification and fastest learning; no automated messages.
2. **LinkedIn campaign-workflow post** — Explain the before/after workflow, show the demo, disclose founder connection, and ask for feedback from marketers using agent skills.
3. **Codex/skills community contribution** — Participate only where current rules permit a relevant, disclosed post. OpenAI Developer Community and RevGenius rules prohibit spam/promotion; use them for helpful participation, not launch blasts. Verify subreddit rules and moderator guidance on the day of posting.
