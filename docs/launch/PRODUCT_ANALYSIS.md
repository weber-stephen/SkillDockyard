# Product analysis

## Positioning

Skill Dockyard helps small marketing teams turn a proven AI workflow into a reviewed, reusable skill for Codex or Claude Code. It solves the gap between a useful prompt in one person's chat and a trusted version the team can use next time.

The first wedge is a marketing lead with 2–10 collaborators using Codex desktop or Claude Code for campaign work. The first job is creating consistent campaign briefs with audience, evidence, message angles, channel ideas, and a sales handoff.

## Evidence in the product

- The public demo, starter collection, and homepage example already include Campaign Brief Builder, Customer Voice Digest, and Sales Discovery Prep.
- The product preserves private drafts, review decisions, published versions, access boundaries, downloads, and update safety.
- Supported installation targets are Codex and Claude Code. Do not imply support for ChatGPT chat, generic prompt libraries, or unsupported desktop apps.

## Alternatives and adoption barriers

Teams currently use chat history, copied prompts, shared docs, local folders, repositories, or no shared process. Skill Dockyard differentiates by combining review and version clarity with reusable skills.

| Segment | Urgency | Accessibility | Signup likelihood | Decision |
| --- | ---: | ---: | ---: | --- |
| Marketing leads using Codex/Claude Code | 8 | 7 | 8 | Primary |
| Sales-enablement leads using agent workflows | 7 | 6 | 7 | Secondary |
| Engineering/platform leaders | 6 | 7 | 6 | Later |

The main barriers are limited awareness of skills, desktop-tool setup, and the need to persuade a collaborator to use a shared workflow. The demo and starter skills reduce the first two; outreach should recruit small teams, not isolated generic-AI users.
